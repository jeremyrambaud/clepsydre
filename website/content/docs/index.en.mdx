## Core value propositions

- **Zero Friction**: Timer control in a click, with fewer missed entries.
- **Deep Integration**: Redmine sync and direct task imputation.
- **Extended Capabilities**: Daily timeline and cross-ticket logging.
- **Holistic Visibility**: Weekly and monthly workload analysis.
