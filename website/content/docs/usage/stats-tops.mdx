---
title: Tops du mois
description: Identifier vos projets et tickets les plus consommateurs de temps.
---

La section **Tops** classe vos projets et tickets par temps imputé sur le mois affiché, pour identifier rapidement où passe votre temps.

<div align="center">![Tops](/images/stats-tops.png)</div>

## Top tickets

Classement des **tickets** par temps cumulé sur le mois. Chaque ligne affiche :

- le **#ID** et l'**intitulé** du ticket ;
- le **temps total** imputé ;
- la **part** correspondante.

## Top projets

Classement des **projets** par temps cumulé sur le mois. Chaque ligne affiche :

- le **nom du projet** ;
- le **temps total** imputé ;
- la **part** que cela représente sur le mois.

## Utilisation

Les tops sont utiles pour :

- repérer les tickets « chronophages » nécessitant un découpage ;
- vérifier l'équilibre entre projets ;
- préparer un reporting mensuel.

<Callout type="info">
Les tops se basent sur le **mois affiché** dans le calendrier. Changez de mois pour mettre à jour les classements.
</Callout>
